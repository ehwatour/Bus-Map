노선 지도 사용 설명서
이 페이지는 지도에서 노선을 확인하고, 필요한 노선만 골라 비교할 수 있도록 만든 노선 지도입니다. 

1. 화면 구성
- 지도: 노선 경로와 정류장 위치를 표시합니다.
- 노선 선택 패널: 노선 목록을 확인하고 표시할 노선을 선택하는 영역입니다.
- ☰/X 버튼: 노선 선택 패널을 열거나 닫습니다.
- 열 표시 메뉴: 노선 목록에 표시할 평일·주말 운행 유형 열을 선택하는
메뉴입니다.

2. 지도에서 노선 확인하기
1) 노선 선택 패널에서 확인할 노선을 찾습니다.
2) 노선명 또는 운행 유형 옆 체크박스를 선택합니다.
3) 선택한 노선이 지도에 표시됩니다. 체크를 해제하면 해당 노선 표시가 꺼집니다.
- 여러 노선을 동시에 선택하면 지도에서 경로를 함께 확인할 수 있습니다.
- 노선은 목록에서 그룹별로 정리되어 있습니다. 그룹이나 노선명 단위로 선택할 수 있고, 운행 유형별로도 개별 선택할 수 있습니다.
- 상위 체크박스는 하위 항목의 선택 상태에 따라 체크 또는 부분 선택 상태로 바뀝니다.

3. 노선 검색
1) 패널 상단의 노선 검색 입력란에 찾을 노선명을 입력합니다.
2) 검색어를 입력하는 동안 일치하는 노선이 목록에 실시간으로 표시됩니다.
3) 검색 버튼을 누르거나 Enter 키를 누르면 현재 검색어를 기준으로 결과가 고정됩니다.
4) 검색을 초기화하려면 입력란의 검색어를 모두 지운 다음 검색 버튼을 누르거나 Enter 키를 누릅니다. 그러면 전체 목록이 다시 표시됩니다.
- 별도의 '검색 해제' 버튼은 없습니다. 검색어를 지우기만 해서는 검색이 고정된 상태가 해제되지 않을 수 있으므로, 입력란을 비운 뒤 Enter 키 또는 검색 버튼으로 확정해야 합니다.
- 검색어는 노선명 일부만 입력해도 사용할 수 있습니다. 여러 단어를 공백으로 구분해 입력하면 해당 단어가 모두 포함된 노선을 찾습니다.

* 검색 결과 전체 선택·해제
- 검색창 옆 체크박스는 검색 결과에 표시된 노선을 한꺼번에 선택하거나 해제하는 기능입니다.
- 열 표시 메뉴에서 숨긴 열은 대상에 포함되지 않습니다.
- 검색 결과만 일괄 변경하려면 먼저 검색어로 대상 노선을 좁힌 뒤 체크박스를 사용하세요.

4. 전체 선택과 전체 해제
- 패널 상단의 버튼을 사용합니다.
- 전체 선택: 노선을 모두 선택합니다.
- 전체 해제: 노선을 모두 해제합니다.
- 특정 노선만 보고 싶다면 전체 해제 후 필요한 노선만 선택하면 편리합니다.

5. 평일·주말 열 표시 설정
- 노선 목록 위의 열 표시 메뉴에서 목록에 표시할 운행 유형 열을 조정할 수 있습니다.
- 평일 / 주말 버튼: 해당 요일의 운행 유형 열을 한꺼번에 표시하거나 숨깁니다.
- 개별 유형 버튼: `주출`, `야출` 등 필요한 운행 유형만 선택해 표시하거나 숨깁니다.
- 이 설정은 목록의 표시 방식만 바꾸는 기능입니다. 지도에 노선을 표시하거나 숨기는 선택 상태와는 별개입니다.
- 목록이 너무 넓거나 확인할 유형이 적을 때 필요 없는 열을 숨기면 원하는 노선을 찾기 쉬워집니다.

6. 패널 크기 조절 및 모바일 이용
- 패널 가장자리의 조절 영역을 좌우로 드래그하면 노선 선택 패널의 너비를 조절할 수 있습니다.
- 패널이 지도를 가리면 X 버튼으로 패널을 닫을 수 있습니다.
- 모바일에서는 화면 폭이 좁으므로, 노선 검색과 열 표시 설정을 이용해 목록을 간단하게 만든 뒤 필요한 항목을 선택하는 방법을 권장합니다.

7. 정류장 확인하기
- 지도에 표시된 정류장 마커를 누르면 해당 정류장의 이름을 확인할 수 있습니다.
- 확대 수준에 따라 배경 정류장 표시의 크기가 달라질 수 있습니다.

9. 참고 사항
- 지도 타일과 Leaflet 지도 라이브러리를 불러오기 위해 인터넷 연결이 필요합니다.
- 지도에 표시되는 노선 및 정류장 정보는 페이지에 포함된 데이터 기준입니다. 실제 운행 정보와 다를 수 있으므로 이용 전 최신 공식
정보를 함께 확인하세요.
